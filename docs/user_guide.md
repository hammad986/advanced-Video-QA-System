# User Guide — Advanced Video QA Pro

Advanced Video QA Pro is a local-first Windows desktop application for researching videos with transcripts, evidence, citations, and multi-video comparison.

## First Run

1. Launch `AdvancedVideoQAPro.exe`.
2. Choose a project workspace folder.
3. Select a runtime profile for your hardware.
4. Configure providers in the Provider Hub if you want cloud answers.
5. Create or open a research project.

## Basic Workflow

1. Import videos into the Video Library.
2. Generate transcripts.
3. Generate knowledge chunks.
4. Generate embeddings and build the FAISS index.
5. Search evidence, ask questions, or compare videos.
6. Export research outputs when finished.

## Workspace

- **Left panel** — projects and video library.
- **Center panel** — video workspace.
- **Bottom panel** — transcript viewer.
- **Right tabs** — chat, compare, knowledge, evidence, bookmarks, highlights, providers, and diagnostics.

## Security

Do not store API keys in source files. Configure provider credentials through the desktop Provider Hub. Keep project workspaces private if they contain sensitive videos or transcripts.
