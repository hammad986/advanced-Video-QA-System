# Portfolio Summary

Advanced Video QA Pro is a local-first Windows desktop video intelligence workbench. It demonstrates desktop application architecture, AI pipeline engineering, local model processing, provider management, retrieval-augmented generation, and production release preparation.

## What It Shows

- PySide6 desktop architecture with persistent layout, settings, diagnostics, and project state.
- SQLite-backed domain model for projects, videos, transcripts, knowledge chunks, embeddings, retrieval, evidence, chat, compare sessions, bookmarks, and highlights.
- Local-first AI pipeline: video transcript generation, semantic chunking, BGE embeddings, FAISS indexing, retrieval, evidence ranking, and grounded answer generation.
- Multi-provider BYOK architecture with encrypted credentials, health checks, safe generation validation, routing, and usage tracking.
- Release engineering: PyInstaller packaging, Inno Setup installer configuration, update-check foundation, release notes, and RC validation evidence.

## Recruiter Signal

This is stronger than a typical AI portfolio demo because it includes product architecture, desktop UX, local model constraints, persistence, release engineering, and real validation artifacts. It is positioned as a serious desktop product prototype approaching V1.0 release readiness.
